Modèle de données

10 tables normalisées (MERISE), contraintes d'intégrité, types énumérés et index.

Un service emploie des agents et traite des dossiers · un usager possède des dossiers · un dossier contient des documents · chaque action sur un document est journalisée.

Règles métier testées automatiquement

8 tests rejoués à chaque modification du code (GitHub Actions + PostgreSQL).

  • Format de fichier non autorisé refusé
  • Dossier clos sans date de clôture refusé
  • Dépôt d'un document journalisé
  • Validation journalisée avec l'agent connecté
  • Document archivé non modifiable
  • Suppression tracée dans l'historique
  • Clôture d'un dossier incomplet refusée
  • Clôture d'un dossier complet acceptée

Exemple de requête

Les 2 agents les plus actifs de chaque service (fonction de fenêtre).

WITH activite AS (
  SELECT s.libelle AS service,
         a.prenom || ' ' || a.nom AS agent,
         count(*) AS actions,
         rank() OVER (PARTITION BY s.libelle
                      ORDER BY count(*) DESC) AS rang
  FROM historique h
  JOIN agent a   USING (agent_id)
  JOIN service s USING (service_id)
  WHERE h.action IN ('creation', 'validation')
  GROUP BY s.libelle, a.agent_id
)
SELECT * FROM activite WHERE rang <= 2;
